# GestWave

Play music in real time using hand gestures detected via your webcam — no keyboard, no mouse.

**[Live Demo](https://hand-gesture-music-controller.vercel.app)**

---

## What It Does

Open the app, click Enable Camera, and show hand gestures to trigger instrument sounds instantly in the browser.

| Gesture | Sound |
|---|---|
| ✊ Fist | Bass |
| ☝️ Index Finger | Kick Drum |
| ✌️ Peace Sign | Snare |
| 🤘 Rock Sign | Synth |
| 🖐️ Open Palm | Hi-Hat |
| 👍 Thumb Up | Tom |

---

## Tech Stack

- **TensorFlow.js + MediaPipe** — real-time hand keypoint detection
- **Tone.js** — audio synthesis in the browser
- **HTML, CSS, JavaScript** — no framework, no backend, no installation

---

## How to Run

```bash
git clone https://github.com/devidasari666-beep/hand-gesture-music-controller.git
```

Open `index.html` in your browser. That's it.
