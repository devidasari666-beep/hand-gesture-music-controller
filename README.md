# 🎵 Hand Gesture Music Controller

Play music with your hand gestures using your webcam — no keyboard, no mouse.

**[Live Demo](https://hand-gesture-music-controller.vercel.app)**

---

## What It Does

Open the app, click Enable Camera, and show hand gestures to play different sounds in real time.

| Gesture | Sound |
|---|---|
| ✊ Fist | Bass |
| ☝️ Index Finger | Kick Drum |
| ✌️ Peace Sign | Snare |
| 🤘 Rock Sign | Synth |
| 🖐️ Open Palm | Hi-Hat |
| 👍 Thumb Up | Tom |

---

## Tech Stack

- **TensorFlow.js + MediaPipe** — detects 21 hand keypoints in real time
- **Tone.js** — plays instrument sounds in browser
- **HTML, CSS, JavaScript** — no framework, no backend

---

## How to Run

```bash
git clone https://github.com/devidasari666-beep/hand-gesture-music-controller.git
```

Open `index.html` in browser. That's it — no installation needed.
